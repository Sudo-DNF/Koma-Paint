Koma MCP Bridge

This plugin opens a localhost-only socket that the Koma Paint MCP server (dev-tools/komapaint-mcp/komapaint_mcp.py in the source tree) uses to inspect and drive Koma Paint: documents, layers, brushes, tools, actions, dockers, widgets, synthetic canvas input, screenshots and a Python console.

Every connection must authenticate with the session token. The port and token are written to komapaint-mcp.json in the user runtime directory (readable by the current user only) and removed when Koma Paint exits.

The bridge executes arbitrary Python sent by the MCP client. Enable it only on machines and sessions you use for development.

Environment variables:

  • KOMA_MCP_PORT: port to listen on (default: any free port).
  • KOMA_MCP_TOKEN: session token (default: random).
  • KRITA_ENABLE_PYTHON_PLUGINS=koma_mcp: load the plugin for this session without enabling it in the settings.
